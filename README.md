# Expenses Tracker

Веб-приложение для совместного учёта расходов. Операции добавляются через форму и записываются
в существующий Excel-файл на личном OneDrive (через rclone). В дальнейшем хранилище будет
заменено на PostgreSQL.

| Папка                  | Что внутри                                          |
| ---------------------- | --------------------------------------------------- |
| [`backend/`](backend)  | Fastify API, запись в Excel, интеграция с OneDrive  |
| [`frontend/`](frontend) | React-форма добавления расхода (PWA)               |

## Статус

MVP v0.1, в работе. Готово: запись в таблицу `Операции`, OneDrive через rclone, API, форма.
Резервные копии Excel, защита от дублей и аудит-лог тоже готовы. Ещё не сделано: авторизация, Docker/Caddy.

## Быстрый старт (локально, Mac)

Требуется Node.js 22.13+ и настроенный rclone с remote `onedrive` (см. [backend/README.md](backend/README.md)).

```bash
./scripts/start-all.sh        # backend + frontend, остановка: Ctrl+C
```

Откройте http://127.0.0.1:5173. Frontend сам проксирует `/api` на backend (`http://127.0.0.1:3000`).

Первая запись после запуска идёт сразу: backend прогревает соединение с OneDrive сам.
Одна запись занимает около 5–7 секунд (подробности и режимы — в [backend/README.md](backend/README.md)).

Скрипт при необходимости сам поставит зависимости, создаст `backend/.env` из `.env.example`,
проверит, что rclone видит файл в OneDrive и что порты свободны. Логи обоих процессов идут в один
терминал с префиксами `[backend]` и `[frontend]`.

| Скрипт                         | Что делает                                            |
| ------------------------------ | ----------------------------------------------------- |
| `scripts/start-all.sh`         | Запускает backend и frontend вместе                   |
| `scripts/start-backend.sh`     | Только backend                                        |
| `scripts/start-frontend.sh`    | Только frontend                                       |
| `scripts/restore-backup.sh`    | Возвращает Excel из резервной копии (`--list` — список) |

Чтобы открыть приложение с телефона в той же Wi-Fi сети, передайте `--host`:
`./scripts/start-all.sh --host`, затем откройте `http://<IP-вашего-Mac>:5173`.

Если скрипт не запускается («permission denied»): `chmod +x scripts/*.sh`.

> **Важно.** Пока файл `Расходы-dev.xlsx` открыт в Excel (в том числе в Excel Online или на
> телефоне), OneDrive блокирует запись и приложение ответит «Файл сейчас открыт в Excel».
> Закройте файл и повторите попытку. Одновременное редактирование файла вручную и через
> приложение в MVP не поддерживается.

## Ограничения MVP

- Excel — единственное хранилище; каждая запись скачивает и загружает файл целиком.
- Нужен доступ к OneDrive, офлайн-режима нет.
- Авторизации пока нет: запускайте только на `localhost`, не публикуйте в интернет.
